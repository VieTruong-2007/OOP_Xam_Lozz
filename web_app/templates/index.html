Hướng dẫn cài đặt

  1. Tải file game ở phần Bản phát hành.
  2. Giải nén hoặc chạy trực tiếp file nếu là .exe.
  3. Nếu dùng máy chủ auth, khởi chạy server trước khi mở game.
  4. Đăng nhập hoặc đăng ký tài khoản rồi bắt đầu chơi.

Chú ý:

Để đảm bảo an toàn, chỉ tải file từ trang này và kiểm tra README-auth.md nếu dùng server đăng nhập.

Thông tin thêm

Web này giúp bạn quản lý và phân phối game dễ dàng. Mỗi file upload nên kèm ghi chú phiên bản để người dùng biết rõ nội dung cập nhật.

  • Phiên bản mới nhất: luôn hiển thị ở đầu danh sách.
  • Admin Upload: chỉ cần đăng nhập để thêm file mới.
  • Hiệu quả: phù hợp cho việc thử nghiệm và chia sẻ nội bộ.
